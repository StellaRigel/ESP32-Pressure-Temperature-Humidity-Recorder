# PHT_2_X — ESP32-S3 气压温湿度记录器（2.x 系列）

> **当前状态**：📋 **v2.2.0 开发中**（新硬件板已打样，固件持续演进中）
> 本仓库公开维护 **PHT 2.x 系列**（2.2 ~ 2.9.x）。3.x 系列将另开 `PHT_3_X`。

一个基于 ESP32-S3 的**长期静置式气压/温湿度记录器**：定时采样、落盘、上屏，
带网页界面与电池管理，面向"放在固定位置连续记录数周"的用途。

---

## 特性

| 模块 | 说明 |
|---|---|
| **传感器** | BMP580（气压）+ SHT30（温湿度）；DS3231 RTC 计时 |
| **采样节拍** | **30 秒一次，严格对齐网络时间的 `HH:MM:00` / `HH:MM:30`** |
| **本地存储** | 采样先入 Flash（环形），**每日 02:00 自动归档到 SD 卡**（CSV，按天分文件） |
| **显示** | ST7305 2.13" 反射式 LCD（常亮），顶栏显示电量/充电/无线状态 |
| **网页界面** | 局域网访问：最新值 / 当日极值 / 24h 变率 / 气压距平曲线 / 日志 / 文件下载 |
| **无线** | WiFi（STA 优先，失败自动开 AP 配网热点）；移动档电池供电时射频全关 |
| **省电** | 移动档 + 电池供电时，**采样间隙浅睡**（RTC 定时唤醒 + GPIO 事件唤醒） |
| **电池管理** | BQ24074 充电 + INA2xx 电压监测 + 电量校准曲线（电压→电量%） |
| **低电保护** | 三档阈值（存档 / 停采 / 深睡），按本机标定曲线自动适配 |

## 硬件（v2.2 板）

### 引脚分配

| 功能 | 引脚 |
|---|---|
| SD 卡 SPI | SCK=**IO5** / CS=**IO7** / MISO=**IO4** / MOSI=**IO6** |
| 屏幕 SPI | CS=**IO40** / DC=**IO41** / RES=**IO42** / SDI=**IO2** / SCK=**IO1** |
| BQ24074 充电 | CE=**IO13** / CHG=**IO9** / PGOOD=**IO10** / EN1=**IO11** / EN2=**IO12** |
| TPS2117 电源切换 | PR1=**IO18**（LDO ⇄ 电池直供） |
| ISET 充电电流 | **IO17**（驱动 MOS） |
| 按钮 | **IO21**（短按交互） |
| I2C | SDA=**IO47** / SCL=**IO48**（3.3 V 域） |
| 总开关 | **EN**（单刀双掷拨动开关） |

### 硬件变更（相对上一版）

- **电源多路复用 TPS2117** 接管"LDO / 电池直供"切换（原 α1 的 MOS 旁路 LDO 方案）
- **LDO 换型**：SPX3819 → **RT9013-33B**
- **电流监测换型**：INA226 → **INA230**（引脚兼容，固件需改身份校验）
- **引脚整体重排**（见上表）
- **按钮改短按**交互；取消 BOOT 按钮；EN 改拨动开关

### ⚠️ 模组引脚禁忌（ESP32-S3-WROOM-1 **N16R8**）

| 引脚 | 说明 |
|---|---|
| **IO26 ~ IO32** | **模组未引出**（内部接 SPI Flash / PSRAM），模组上没有这些焊盘 |
| **IO35 / IO36 / IO37** | **已接模组内部 Octal PSRAM**，绝对不可用于其他功能 |
| **IO0 / IO3 / IO45 / IO46** | Strapping 脚 —— 本项目均未分配 |
| **IO45** | **绝对不许加上拉/下拉/跳线**（它决定 VDD_SPI 电压；误配成 1.8 V 会废掉整组 3.3 V I2C 器件） |
| IO19 / IO20 | USB D- / D+ |
| IO43 / IO44 | 串口日志（U0TXD / U0RXD） |

## 构建与烧录

### 环境

- **Arduino IDE 2.x**（或 `arduino-cli`）
- **ESP32 Arduino core 3.3.x**
- 开发板：**ESP32S3 Dev Module**

### FQBN

```
esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi,PartitionScheme=custom,FlashMode=qio,CPUFreq=240,CDCOnBoot=cdc
```

> ⚠️ **必须是自定义分区表**（`PartitionScheme=custom`）；`PSRAM=opi` 对应模组的 Octal PSRAM。

### 命令行烧录

```bash
arduino-cli compile --fqbn "<上面的 FQBN>" PHT_2_X
arduino-cli upload  --fqbn "<上面的 FQBN>" -p <串口> PHT_2_X
```

> **踩坑提醒**：工程路径含空格 / `+` / 中文时，自定义分区表的 COPY recipe 可能报
> `The syntax of the command is incorrect`。**解法**：把 `.ino/.h/.csv` 复制到纯 ASCII 短路径再编译。

## 隐私与安全

⚠️ 本仓库**公开**，因此：

- **`wifi.json`（保存的 WiFi 列表，含真实口令）不会入库** —— 见 `.gitignore`
- 固件里的 `WIFI_SSID` 默认为**空**，由用户在配网时填写
- AP 配网热点默认口令 `12345678` —— **首次使用请务必修改**
- 标定数据（`battcal.*`）、设备日志（`*.log`）均不入库
